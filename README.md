# RaidPartyLeader

Аддон для «Аллодов Онлайн»: сохраняет группу или отряд и собирает его заново в пару кликов — приглашает,
расставляет по группам и местам, выдаёт роли и выставляет дележ добычи.

![Окно RaidPartyLeader](release/promo/RaidPartyLeader-1-cover.png)

Версия 0.11.0 (бета). Автор — NoMercy.

## Что умеет

- **Сохранение.** Состав, места в группах, лидер, помощники, ответственный за добычу, схема дележа и минимальная
  ценность предметов. Изменившийся состав можно обновить или сохранить как новый.
- **Сборка.** Группа собирается одной кнопкой. Отряд — с нуля: аддон зовёт первого по местам, группа сама
  превращается в отряд нужного типа, остальные приглашаются следом. Когда пришли все, аддон расставляет их по местам,
  выдаёт роли и выставляет дележ.
- **Быстрый сбор.** ПКМ по кнопке RPL запоминает текущий состав, Shift+ПКМ собирает его — окно открывать не нужно.
- **Управление отрядом.** Перенос и обмен местами между группами, помощники, ответственный за добычу, исключение,
  передача лидерства, проверка готовности с итогом.
- **Индикатор на кнопке.** Зелёный — состав совпадает с сохранённым, жёлтый — идёт сборка или что-то отличается,
  красный — вы в группе или отряде, который не сохранён.

Полное описание, права и ограничения — [release/description.html](release/description.html), список изменений —
[release/changes.md](release/changes.md).

## Установка

1. Скачайте `RaidPartyLeader.pak` со страницы [Releases](../../releases).
2. Положите файл в `<папка игры>\data\Mods\Addons\`. При обновлении новый файл заменяет прежний.

## Управление

| Действие | Что делает |
| --- | --- |
| ЛКМ по кнопке RPL | открыть или закрыть окно |
| ПКМ по кнопке RPL | запомнить текущий состав в «Быстрое» |
| Shift+ПКМ по кнопке RPL | собрать «Быстрое»; в своём формировании — дозвать недостающих и расставить по местам |

Кнопку и окно можно перетаскивать. Сохранённые формирования у каждого персонажа свои, положение кнопки и окон —
общее для всех персонажей.

## Ограничения

- Приглашать, переставлять и назначать роли аддон может только там, где это разрешает игра: лидеру, а часть
  действий — ещё и помощнику.
- Игроки с других серверов и из другой фракции не сохраняются.
- Малый отряд и отряд друг в друга не превращаются: чтобы собрать отряд другого типа, из текущего нужно выйти.
- Аспект определяется по баффам игрока и для редких аспектов может не появиться.

# Разработчикам

```
lua/       скрипты в UTF-8 (при сборке переводятся в Windows-1251; LibDnD.lua — как есть)
res/       готовые ресурсы аддона: AddonDesc, виджеты, тексты, текстуры
gen/       assemble.py собирает папку аддона из res/ и lua/, pak.py — RaidPartyLeader.pak;
           res/ — генератор ресурсов (нужен, только если меняете виджеты и текстуры)
tools/     strip_debug.py — вырезает отладку из скриптов при сборке
test/      прогон логики на заглушках API игры
release/   описание, список изменений и карточки текущего выпуска
```

## Сборка

Нужен Python 3.

```
python3 gen/assemble.py out/RaidPartyLeader                     ->  папка аддона
python3 gen/pak.py out/RaidPartyLeader out/RaidPartyLeader.pak  ->  файл для data\Mods\Addons
```

Версия задаётся в одном месте — `RPL.VERSION` в `lua/Util.lua`. Отладочная сборка — с переменной `ALLODS_DEBUG=1`.

Ресурсы в `res/` лежат готовыми. Их пересобирает `python3 gen/res/make.py` (нужен `Pillow`); иконки классов
и аспектов генератор берёт из распакованных ресурсов игры — путь к папке `Interface` задаётся в `RPL_ASSETS`.

## Тесты

```
sh test/run.sh
```

Логика аддона прогоняется на заглушках API игры дважды: обычная сборка и отладочная. Нужны Python 3 и `texlua`,
`luajit` или `lua5.1` (свой интерпретатор — `LUA=<путь>`). Те же проверки запускаются в GitHub Actions на каждый
pull request.

## Ветки и выпуски

`main` — только выпущенное. Доработка — в ветке `feature/<коротко>` или `fix/<коротко>` и через pull request.
Выпуск — слияние в `main` и тег `v<версия>`: по тегу GitHub Actions собирает `RaidPartyLeader.pak` и создаёт выпуск
с описанием из `release/changes.md`.
